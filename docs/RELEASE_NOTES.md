# ✈️ 长龙航空 · 畅飞智能助手 v2.1.0 发布说明

长龙航空畅飞助手（LoongAir Helper）v2.1.0 正式发布！本版本重点围绕**全平台移动端沉浸体验**、**极简美学重构**与**航线巡检效率**进行全面进化。

---

## 🚀 核心更新亮点

### 1. 📱 移动端与多视口深度兼容 (Mobile-First Experience)
- **全新单行紧凑筛选器**：移动端筛选栏高度全面压缩至 65px，出发地 ⇄ 目的地单行自适应排布，支持一键互换，单手操作更顺畅。
- **现代化视口防溢出下拉**：彻底解决移动端原生 Select 溢出屏幕的问题，全面升级为与桌面端一致的现代组件，支持城市、省份与拼音全拼/首字母即时搜索。
- **地图探索触控手势**：消除移动端地图视口上下黑边，支持单指拖拽平移与双指自然捏合缩放（Pinch-to-zoom）。
- **模态框底部抽屉交互 (Bottom Sheet)**：所有弹窗（航线巡检、放票日历、登录认证等）在手机端均自适应为 Bottom Sheet 底部拉起抽屉，贴合手势习惯。

### 2. ⚡ 航线巡检模态框极简化与美学重构
- **Tab 1（重点监控航线）**：
  - 剔除传统死板表格，重构为高辨识度航线卡片流；
  - 移除多余的 Emoji 与冗余文字，去除底部“清空与导入示例”扰动元素，视觉呼吸感拉满；
  - 统一连接箭头为极简 `➔` 符号。
- **Tab 2（全网直飞大普查）**：
  - 彻底重构多层分散的色块与条目，将每日定时普查与时间点配置融为一体化微卡片；
  - 底部双 Tab 操作结构严格对称统一：`▶ 立即巡检` / `▶ 立即全网普查` 与 `保存配置`，主从层级分明。

### 3. 🎯 核心数据与筛选逻辑净化
- **直飞拓扑与数据源校验**：修正仅看有票开关切换时航线总数保持不变的问题，数据源现包含全量 397 条航线直飞拓扑；
- **纯粹信息展现**：彻底剥离全网接驳漫游方案与多余的“联网”文案，去除华东/西北等无效行政大区文字标签，直接呈现城市与所属省份，降低信息噪点。

### 4. 🤖 Model Context Protocol (MCP) 原生协议支持
- **6 大核心 MCP 工具**：涵盖实时长龙官方查票（即时余票/起降时间）、60天放票日历大盘检索、直飞拓扑探索、重点航线监控管理以及会员资产档案；
- **双模接入极速支持**：既支持标准 stdio 管道（如 `docker exec -i clairline python -m backend.mcp_server`），又原生提供 `http://IP:3000/sse` 网络流端点，无缝挂载至 Claude Desktop、Cursor、Antigravity 与各类大模型 Agent。详细文档参见 [docs/MCP_GUIDE.md](MCP_GUIDE.md)。

## 🐳 Docker 官方多架构镜像 (NAS / 24h 自动巡检)

前后端一体化极轻量容器（仅 ~100MB），免环境配置、免拉取代码，直接运行：

```bash
docker run -d \
  --name clairline \
  --restart unless-stopped \
  -p 3000:3000 \
  -v ./data:/app/backend/data \
  -e TZ=Asia/Shanghai \
  ghcr.io/eureka-wu/clairline:latest
```

> 💡 **提示**：Web 网页端已全量支持 PWA 与手机浏览器响应式访问，建议在移动设备上“添加到主屏幕”获得类原生 App 体验。
