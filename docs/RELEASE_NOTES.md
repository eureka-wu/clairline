# ✈️ 长龙航空 · 畅飞智能助手 v2.1.2 发布说明

长龙航空畅飞助手（LoongAir Helper）v2.1.2 正式发布！本版本迎来重大底层协议演进，**正式突破并支持长龙官方手机 App 原生移动端长效协议（`SaleChannel: 8`）**，并彻底拔除了历史遗留的本地跨天主动清空凭据的缺陷，实现真正的**超长免登持久化查票**。

---

## 🚀 核心更新亮点

### 1. 📱 突破性支持长龙官方 App 原生移动端长效协议 (`SaleChannel: 8`)
- **摆脱微信小程序短效限制**：全面适配长龙航空官方移动端原生网关协议。不同于微信小程序强加的 24 小时短命 Session，App 渠道采用移动端长效鉴权体系（`Base64SessionID` + 原生设备内核通信）；
- **一次配置，超长免登**：会员凭证在长龙服务端的存活周期大幅延长（通常达数周至数月），彻底告别天天被动接短信验证码的烦恼；
- **双模自适应分流**：系统底层具备渠道嗅探能力，自动识别 App 凭据与微信短信凭据，智能分发专属 Header 与请求通道。

### 2. 🛠️ 彻底根除历史“跨天本地清空凭据”的代码缺陷
- **拔除本地自杀逻辑**：修复此前底层代码中存在的 `if up_time != today_str: self.headers = {}`（北京时间一过 0 点本地代码主动自杀清空凭证）的严重逻辑陷阱，解开了“即使抓包次日也会失效”的历史死结；
- **服务端探针唯一裁决**：凭据的存活状态 100% 移交长龙服务端真实状态裁决，本地绝不再盲目判断过期。

### 3. 🔑 短信直登优化：自动预填手机号与 3 秒极速续期
- **告别误导死循环**：修复此前短效凭据到期后弹窗错误展示“会员凭证已生效”导致无法重新输入验证码的交互 Bug；
- **全自动预填手机号**：到期弹窗自动检测已绑定的会员手机号并预填，免去重复输入 11 位数字，仅需点击【获取验证码】完成极速滑块验证，填入 6 位验证码后点击【立即验证并完成续期】，3 秒无感恢复查票；
- **顶部胶囊状态感知**：凭据到期后，顶部导航栏即刻呈现橙色提醒胶囊 `【会员名 (已到期·点此续期)】`，原因与动作一目了然。

### 4. 🛡️ 隐私与设备指纹物理隔离安全设计
- **本地私有落盘隔离**：用户的会员账号、真实姓名、手机号、身份证号与 Session Cookie 仅保存在用户本地电脑的 `changlong.db` 数据库中，受 `.gitignore` 严密防护，开源代码绝不携带任何具体用户隐私；
- **多用户防风控设计**：代码层解耦通用接口协议与具体设备指纹，杜绝多用户并发特征雷同。
