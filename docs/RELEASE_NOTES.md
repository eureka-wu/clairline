# ✈️ 长龙航空 · 畅飞智能助手 v2.1.1 发布说明

长龙航空畅飞助手（LoongAir Helper）v2.1.1 紧急稳定性修复版本正式发布！本版本重点修复了**手机登录态持久续期**与**版本自动检测弹窗**等关键体验问题。

---

## 🛠️ 关键修复与体验优化

### 1. 🔑 手机验证码登录持久化与自动无感续期
- **长效 refreshToken 正式持久化落盘**：修复此前 SQLite 数据库缺少字段导致长效刷新令牌未保存的严重缺陷。现在使用短信验证码登录一次后，长效凭据永久写入本地数据库；
- **API 403 / 100001 毫秒级自动换票重试**：当短效 Token 过期时长龙返回未登录或 403 时，底层网络请求自动捕获并调用官方刷新接口无缝换新 Token，并自动重试查票，对用户完全无感；
- **智能跨天与凌晨静默预续期**：次日打开客户端或跨天轮询时，系统后台自动提前刷新 Token，彻底告别“第二天退出登录 / 重新输入验证码”的困扰。

### 2. 🔔 版本更新检测与导航栏胶囊全面修复
- **冷启动自动更新提示弹窗**：修复 `App.vue` 中因条件判断导致冷启动检测到新版本却未自动弹出模态框的逻辑 Bug。新版本发布后，旧版客户端打开即可立即收到精美更新弹窗；
- **右上角版本展示胶囊恢复**：恢复顶部导航栏【版本胶囊】按钮，平时展示当前运行版本（`v2.1.1`），检测到新版本时高亮显示绿色“新版可用”，支持一键直达 GitHub Releases 下载最新安装包。
