# ✈️ 长龙航空 · 畅飞智能助手 v2.1.2 发布说明

长龙航空畅飞助手（LoongAir Helper）v2.1.2 稳定性与会员续期体验修复版本正式发布！本版本重点彻底根除了**跨天使用时凭据过期、弹窗死循环显示“已生效”而无法续期**的交互缺陷，升级为**自动预填手机号、一键短信极速续期**模式。

---

## 🛠️ 关键修复与体验优化

### 1. 🔑 根除凭据过期死循环与“假生效”困扰
- **彻底消除弹窗误导**：修复此前次日短效凭证过期（长龙官方 Session 约 24h 有效期）后，弹窗错误展示“会员凭证已生效”且隐藏验证码表单，导致用户无法重新验证、刷新放票无限报错 401 的恶性循环问题；
- **状态精准识别与全局同步**：后端建立细粒度凭据失效探针，当检测到跨天超过 18 小时或捕获到长龙官方 `100001` / `403` 未登录时，准确感知 `is_expired: true`，前后端实时保持步调一致。

### 2. ⚡ 手机号自动预填与 3 秒一键验证续期
- **顶部胶囊状态感知**：凭据到期后，顶部导航栏即刻呈现醒目的橙色胶囊 `【会员名 (已到期·点此续期)】`，原因与动作一目了然；
- **免重复输入手机号**：到期弹窗自动检测已绑定的会员手机号并完成预填，用户无需每次重复输入 11 位数字，仅需点击【获取验证码】完成极速滑块，填入 6 位验证码后点击【立即验证并完成续期】，3 秒无感恢复查票；
- **续期后流水线自动恢复**：验证续期成功后，模态框自动静默关闭，日历刷新与全网航线巡检自动续接运行。

### 3. 🌐 官方底层网关适配修复
- **HTTP 201 状态码兼容**：修复此前接口层仅识别 HTTP 200 导致长龙网关返回 201 时被误判为空响应的底层缺陷；
- **网关路由参数纯化**：彻底剔除触发长龙网关 Spring Cloud Gateway 404 路由异常的冗余大写参数，接口通信稳定顺畅。
