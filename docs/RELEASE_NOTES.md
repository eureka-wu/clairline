# ✈️ 长龙航空 · 畅飞智能助手 v2.1.2 发布说明

### 🛠️ 核心更新
1. **支持官方 App 原生长效协议**：全面接入 App 移动端网关（SaleChannel: 8），告别微信小程序 24h 短命 Session，实现超长免登；
2. **彻底修复跨天自动清空缺陷**：移除本地每日 0 点粗暴清空凭据的代码，凭据有效性完全由长龙服务端真实状态裁决；
3. **短信直登优化**：自动预填已绑定手机号，消除弹窗误导死循环，提供 3 秒一键短信快速续期；
4. **底层网关与隐私安全**：全面兼容长龙网关 HTTP 201 状态码，个人凭据本地数据库物理隔离、绝对不上传开源代码。
