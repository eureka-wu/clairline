# 长龙航空 · 畅飞卡智能大盘与航网规划助手 (Vue 3 + Vite)

> 一款专为长龙航空「畅飞卡 / 随心飞」旅客打造的高颜值、现代工程感航网探索与兑换决策分析平台。  
> 前端采用 **Vue 3 + Vite + ECharts** 现代化单页架构，后端由 **Python 3 + SQLite3 数据库** 驱动。  
> 实时全景可视化中国航线网、近 60 天长龙官方放票动态日历、高铁周边延伸接驳漫游、余票持久化与自动化后台巡检。

---

## 🌟 核心特性与架构升级

- ⚡ **Vue 3 + Vite 现代工程体系**：告别单体脚本，全面转向 Vue 3 组合式 API (`<script setup>`) 与组件化开发，毫秒级热更新，生产打包仅需 3.4 秒；
- ✈️ **全网直飞航线大盘 (1280px 居中)**：收录 71 座通航城市、398 条直飞航线，消除超宽屏中空，支持拼音秒搜、城市双向互换与严格直达级联；
- 🗺️ **ECharts 航网动态飞线大屏**：
  - 航线色阶分级：根据未来可兑天数（20+天充裕、10~19天常态、1~9天紧俏、无票）动态映射亮度与线宽；
  - **近期票流动粒子特效**：近 7 天内有票的航线自带流动发光粒子流光动画；
  - 自由缩放漫游：支持滚轮自由缩放（Zoom）与平移（Pan），城市节点防重叠，带一键“恢复全貌”与航网图例；
  - 点击互动：点击目的地直接滑出 60 天详情抽屉，点击其他枢纽快速切换出发城市；
- ⏱️ **SQLite 在库持久化与 0ms 就地微气泡**：
  - 任何日期点击查验后，各班次剩余张数、时刻、机型永久落库到本地 SQLite `seat_queries` 表；
  - 刷新页面（F5）瞬间自动回显绿色微标（如 `余3 · 09:30查`），再次点击 **0 毫秒直接从数据库弹窗**，零网络请求、零风控；
  - 微气泡彻底去除技术型文案与杂乱彩色 Emoji，仅保留纯净时间戳；
- 🛡️ **智能排班跨度提炼**：单班航线显示 `首选单班 · 06:30 ➔ 15:20`，多班航线智能提炼 `全天共 6 班 · 首班 06:30 ~ 末班 17:10`，彻底解决首末班时间一致的旧缺陷；
- 🕒 **核心巡检航线配置模态框**：支持自定义 30 条核心航线（满载锁定）、后台每 25 分钟慢速拟人轮巡开关、全量普查定时点配置与实时百分比动态进度条。

## 🚀 快速启动

### 环境要求
- **Node.js** 18.0+ / npm 9.0+
- **Python** 3.8+
- 现代浏览器（Chrome / Edge / Safari 等）

### 运行方式（Windows 一键运行）
双击项目根目录下的 **`start.bat`**：
- 自动检测并初始化前端依赖与生产打包产物；
- 自动启动 Python 后端服务（统一托管 API 与前端单页应用）；
- 自动唤起浏览器打开 `http://localhost:3000`。

### 开发者模式 (前后端独立开发)

#### 1. 启动后端 API 服务
```bash
python backend/server.py
```
后端将在 `http://127.0.0.1:3000` 监听。

#### 2. 启动前端 Vite 极速热更新
```bash
cd frontend
npm install     # 首次运行安装依赖
npm run dev     # 启动 Vite 开发服务器
```
浏览器访问 `http://localhost:5173`，所有 `/api` 请求将自动代理至后端。

#### 3. 编译生产版本
```bash
cd frontend
npm run build   # 输出至 frontend/dist
```
编译产物由 Python 后端 `server.py` 原生高并发分发。

## 🔐 凭据与实时查验机制说明

本项目提供**两种使用模式**：

### 模式一：开箱即用模式 (默认 · 无需任何配置)
- **场景**：浏览全网 398 条航线大盘、查看近 60 天放票日历、规划周末出行、查看高铁接驳方案与航网流动光效地图。
- **说明**：SQLite 数据库自带最新全网放票大盘，**无需任何登录账号或抓包文件**，克隆后双击 `start.bat` 即可完整体验全部核心功能。

---

### 模式二：实时余票穿透查验 (进阶 · 配置个人抓包文件)
- **场景**：点击具体日期穿透探测长龙官方系统该趟航班当前具体剩余可兑张数（`secCardLeft`），并自动持久化写入本地 SQLite。
- **存放路径**：**`backend/data/cl.saz`**（亦兼容 `backend/data/changlong.saz` 或项目根目录）。
- **获取步骤**：
  1. 使用 **Fiddler Classic** 开启 HTTPS 解密；
  2. 手机或电脑打开微信「长龙航空」小程序，进入「畅飞卡」专区点开任意航线查一次票；
  3. Fiddler 点击 `File` ➔ `Save` ➔ `All Sessions...`，保存为 **`cl.saz`**；
  4. 存放到 `backend/data/cl.saz`，重启服务即可享受实时穿透查票。
