# 长龙航空 · 畅飞卡智能大盘与航网规划助手

> 一款专为长龙航空「畅飞卡 / 随心飞」旅客打造的高颜值、现代工程感航网探索与兑换决策分析平台。  
> 实时全景可视化中国航线网、近 60 天长龙官方放票动态日历、高铁周边延伸接驳漫游、多航段中转规划与税费综合测算。

---

## 🌟 核心特性

- ✈️ **全网直飞航线大盘**：收录 71 座通航城市、398 条直飞航线，支持城市点击聚焦与双向航线反查；
- 🗺️ **交互式矢量中国航图**：采用中国省份地理坐标投影，支持滚轮平滑缩放、拖拽漫游、长三角等密集集群放射状防重叠排版；
- 📅 **近 60 天可兑换出行日历**：按周几、周末高亮呈现各航线放票出行日，直观标注官方放票批次；
- ⏱️ **实时余票查验与时间戳**：支持直连官方查验航班具体剩余可兑席位（`secCardLeft`），胶囊带时间微注，本地自动持久化；
- 🚄 **高铁跨城接驳与延伸漫游**：智能识别周边高铁接驳枢纽，落地后延伸漫游推荐（如阿勒泰滑雪接驳、喀什/版纳延伸规划）；
- 💰 **税费与单次出行成本测算**：支持自定义机建燃油税费阶梯（机建 ¥50，燃油 ¥90），即时测算回本进度与出行成本。

## 🔐 使用模式与凭据说明

本项目针对不同需求提供**两种使用模式**：

### 模式一：开箱即用模式 (默认 · 无需任何配置)
- **适合场景**：快速浏览全国航线网、查看近 60 天放票日历、规划周末/节假日出行、查找高铁接驳方案。
- **说明**：仓库内自带预编译的脱敏航网数据库与日历总览，**无需任何登录账号、Cookie 或抓包文件**，克隆后双击 `start.bat` 即可完整体验 90% 以上核心功能。

---

### 模式二：实时余票穿透查验 (进阶 · 需配置个人抓包文件)
- **适合场景**：想要在网页上直接点击具体日期，穿透向长龙官网抓取“此刻这趟航班具体还剩几张可兑票（`secCardLeft`）”。
- **原理**：长龙航空微信小程序接口受网易易盾 WAF 与动态 Token 保护。后端客户端内置了自动解析引擎，只需读取你本人的 Fiddler 抓包文件 `cl.saz`（亦兼容 `changlong.saz`），即可自动提取认证头并发起官方请求。

#### 📌 抓包文件命名与存放规范：
- **推荐命名**：**`cl.saz`**（长龙首字母缩写，压缩导出时直接命名为 `cl.saz` 即可）；
- **兼容命名**：`changlong.saz`（全拼原名同样自动兼容识别）；
- **存放路径**：**`backend/data/cl.saz`**；
- **自适应寻址**：后端启动时会自动探测 `backend/data/cl.saz` ➔ `backend/data/changlong.saz` ➔ 项目根目录或桌面，开箱即识。

#### 💡 手把手获取 `cl.saz` 步骤：

1. **准备抓包工具**：
   - 推荐使用免费的 **[Fiddler Classic](https://www.telerik.com/fiddler/fiddler-classic)**（Windows）或 **Charles** / **HTTP Toolkit**。
2. **开启 HTTPS 解密**：
   - 打开 Fiddler ➔ 顶部菜单 `Tools` ➔ `Options` ➔ `HTTPS` 选项卡；
   - 勾选 `Capture HTTPS CONNECTs` 与 `Decrypt HTTPS traffic`；
   - 根据提示信任并安装 Fiddler 根证书（用于解密微信小程序 HTTPS 通信）。
3. **在微信中发起一次查询**：
   - 打开 PC 微信或手机（连接同局域网代理）；
   - 进入微信小程序 **「长龙航空」** ➔ 找到 **「畅飞卡」** 专区；
   - 随意选择一条航线（如杭州飞北京），点击查询航班；
   - 点开任意一个日期的放票日历。
4. **导出抓包文件**：
   - 回到 Fiddler 窗口，点击左上角菜单：`File` ➔ `Save` ➔ `All Sessions...`；
   - 将文件命名为 **`cl.saz`**；
   - 将该文件移动存放到本项目的 **`backend/data/`** 目录下（即 `backend/data/cl.saz`）。
5. **生效验证**：
   - 重启后端服务（关闭黑窗口重新双击 `start.bat`）；
   - 在网页上点击任意日期胶囊，系统将自动发起实时查验并呈现精准剩余张数！

## 🔄 全网 398 航线官方放票大盘更新指南 (开发者进阶)

> 💡 **重要说明**：本项目仓库已预置了最新编译的脱敏全网放票日历数据库。**普通用户完全不需要执行此步骤**，开箱即可直接查看全部航线近 60 天放票日历。

如果你是开发者或站长，后续在航司放票周期（如半个月或换季）想要**将全网 398 条航线的可兑换出行日历全量刷新至最新**，工作流如下：

1. **准备凭据**：确保 `backend/data/cl.saz` 放置了最新的抓包凭证；
2. **执行全网双并发扫描**：
   ```bash
   python backend/batch_scanner.py
   ```
   - **机制**：采用受控双并发架构（2 个 Worker 错峰交替，发包节奏严格控制为 ~1.1 秒/条，带随机微抖动与断点续存）；
   - **耗时**：约 6.5 ~ 7.5 分钟，安全、平稳地抓取全国 398 条航线未来 60 天官方放票状态，输出为 `backend/data/full_network_calendar.json`。
3. **一键编译同步至前端**：
   ```bash
   python backend/trim_calendar_60days.py
   ```
   - 自动裁切有效 60 天出行窗口，剔除无效航线，同步生成前端专用的 `frontend/js/available-routes-data.js` 与 JSON。
4. **刷新页面**：前端即可呈现最新批次的放票大盘数据！

### ⏱️ 定时巡检与防风控建议 (避坑指南)

若计划挂服务器进行自动化定时更新，**切勿无脑全量高频轮询**（全网 398 条 × 每小时 2 次 = 每天近 2 万次请求，极易被长龙网易易盾 WAF 识别为爬虫并 403 封锁 IP）。推荐**分级动静巡检策略**：

| 巡检层级 | 监控范围 | 推荐频率 | 核心收益与耗时 |
| :--- | :--- | :--- | :--- |
| **Tier 1 (核心热门)** | Top 30 热门航线（杭州出疆/三亚/版纳/成都等） | 20 ~ 30 分钟/次 | **耗时约 2 ~ 3 分钟**（放缓慢速巡检，每条间隔 4~5 秒模拟真人，极其安全） |
| **Tier 2 (全网全量)** | 全国 398 条直飞航线全量大盘 | 每天 1 ~ 2 次 (早 9:00 / 晚 20:00) | 耗时 ~7 分钟，锁定航司放票黄金节点全量刷新 |
| **夜间避让** | 全网所有任务 | 00:00 ~ 07:00 彻底静默休眠 | 航司半夜不放票，规避深夜异常发包特征 |

项目已内置开箱即用的自动化巡检守护机器人：
```bash
# 启动 7x24h 自动化分级巡检守护进程 (白天每 25 分钟自动慢速巡检热门，早晚自动普查全网)
python backend/auto_patrol.py

# 快速单次测试：仅立即执行一次 Top 30 核心热门巡检 (~2分钟慢速完成并自动同步前端)
python backend/auto_patrol.py --once-hot

# 快速单次测试：仅立即执行一次全网 398 条全量普查 (~7分钟完成)

```

## ❓ 常见问题 (FAQ)

- **Q1: 为什么点击查询余票提示“后台接口未就绪”？**  
  答：说明你处于【模式一】，未在 `backend/data/` 放入 `cl.saz`。此时不影响看放票大盘，你可以直接打开手机长龙 App 预约出票；若想在网页查具体余票数，请参考进阶步骤放置抓包文件。
- **Q2: 退出微信小程序后，之前查票好好的突然提示失效或 403？**  
  答：微信小程序一旦在手机上被“退出登录”或被微信清理后台缓存，长龙服务器会将之前的 Session/Token 主动注销。**解决方法非常简单**：手机重新打开微信「长龙航空」小程序，进畅飞卡专区随意点开查一次票，Fiddler 重新另存为 `cl.saz` 覆盖到 `backend/data/cl.saz` 即可立刻恢复！
