# 长龙航线 · 智能大盘与航网规划助手 (Vue 3 + Vite)

> 一款专为长龙航空旅客与常旅客打造的高颜值、现代工程感航网探索与兑换决策分析平台。  
> 前端采用 **Vue 3 + Vite + 原生轻量矢量 SVG 动态航网** 现代化单页架构，后端由 **Python 3 + SQLite3 数据库** 驱动。  
> 实时全景可视化中国航线网、近 60 天长龙官方放票动态日历、高铁周边延伸接驳漫游、余票持久化与自动化后台巡检。

## 🌟 核心特性与架构升级

- ⚡ **Vue 3 + Vite 现代工程体系**：全面转向 Vue 3 组合式 API (`<script setup>`) 与组件化开发，毫秒级 HMR 热更新，代码修改即刻呈现，无需频繁打包；
- ✈️ **全网直飞航线大盘 (1280px 居中 · 吸顶筛选)**：
  - 收录 71 座通航城市、398 条直飞航线，消除超宽屏空旷感；
  - **筛选栏 Sticky 粘性吸顶**：长列表向下滚动时，出发地/目的地/排序工具栏自动吸附在顶部导航紧下方，随时切换筛选；
  - **卡片精简化设计**：去除多余的里程与直飞标签，界面视觉纯粹聚焦于出发时刻、排班频次与日期余票；
- 🗺️ **原生矢量 SVG 航网漫游与全屏大屏**：
  - **纯净两档色阶**：绿线（近 7 天有票 / 20+ 天充裕可兑）vs 灰线（1~9 天紧俏散票），单一色彩纯净显色，杜绝多种颜色在同一直线上重叠混淆；
  - **近期票流动粒子特效**：近 7 天内有票的航线自带流动发光粒子流光动画；
  - **一键全屏沉浸大屏**：地图右上角提供极简纯图标全屏切换，全屏时自适应铺满整块显示器并自动隐去 Header，**全屏状态下完美支持城市聚焦筛选框下拉搜索，点击航线右侧抽屉弹窗顺畅滑出**；
  - **地图视口防遮挡防晃动**：地图模式下锁定页面纵向滚动，滚轮缩放与平移完全局限在地图内部，避免外层滚动导致 Header 遮挡控制条；带一键“恢复全貌”；
- ⏱️ **SQLite 在库持久化与智能保活微气泡**：
  - 本地 SQLite WAL 高性能模式存储（2.4 万+ 条全网放票日历与排班记录，单次点查 < 0.5ms）；
  - 任何日期点击查验后，各班次剩余张数、时刻、机型永久落库到本地 SQLite `seat_queries` 表；
  - 刷新页面（F5）瞬间自动回显绿色微标（如 `余13 · 11:04查`），再次点击 **0 毫秒直接从数据库弹窗**，零网络请求、零风控；
  - **气泡悬停抗塌缩与智能保活**：在微气泡内点击【刷新】时原有列表平滑保留，高度绝不跳动塌缩，鼠标停留在气泡或胶囊上时持续保活，移开后延时 280ms 优雅淡出；
- 🛡️ **智能排班跨度提炼**：单班航线显示 `首选单班 · 06:30 ➔ 15:20`，多班航线智能提炼 `全天共 4 班 · 首班 06:50 ~ 末班 21:50`，彻底解决首末班时间一致的旧缺陷；
- 🕒 **核心巡检航线配置模态框**：支持自定义 30 条核心航线（满载锁定）、后台每 25 分钟慢速拟人轮巡开关、全量普查定时点配置与实时百分比动态进度条。

## 🚀 快速启动

### 环境要求
- **Node.js** 18.0+ / npm 9.0+
- **Python** 3.8+
- 现代浏览器（Chrome / Edge / Safari 等）

### 运行方式（Windows 一键运行）
双击项目根目录下的 **`dev.bat`**：
- 自动启动 Python 后端 API 服务（监听端口 `3000`）；
- 自动启动 Vite 前端开发服务器（监听端口 `5173`，支持 HMR 热更新）；
- 修改代码即刻在浏览器热生效，无需每次手动 build 打包。

### 开发者模式 (前后端独立调试)

#### 1. 启动后端 API 服务
```bash
python backend/server.py
```
后端将在 `http://127.0.0.1:3000` 监听。

#### 2. 启动前端 Vite 极速热更新
```bash
cd frontend
npm install     # 首次运行安装依赖
npm run dev     # 启动 Vite 开发服务器 (端口 5173)
```
浏览器访问 `http://localhost:5173`，所有 `/api` 请求将通过 Vite 代理自动转至 3000 后端。

#### 3. 生产静态构建 (可选)
```bash
cd frontend
npm run build   # 输出至 frontend/dist
```
编译产物可由 Python 后端 `server.py` 原生高并发静态分发。

## 🔐 凭据与实时查验机制说明

本项目提供**两种使用模式**：

### 模式一：开箱即用模式 (默认 · 无需任何配置)
- **场景**：浏览全网 398 条直飞航线大盘、查看近 60 天放票日历、规划周末出行、查看高铁接驳方案与航网流动光效地图。
- **说明**：**基础数据库已随仓库直接上传！** 仓库已内置当前（2026-10-23）的 `backend/data/changlong.db`（包含全网 71 座城市、398 条航线排班与近 60 天放票日历，总计 24,000+ 条真实大盘数据）。**无需任何登录账号或抓包文件**，克隆后直接双击 `dev.bat` 即可开箱完整体验全部核心功能。

---

### 模式二：实时余票穿透查验 (进阶 · 配置个人抓包文件)
- **场景**：点击具体日期穿透探测长龙官方系统该趟航班当前具体剩余可兑张数（`secCardLeft`），并自动持久化写入本地 SQLite。
- **存放路径**：**`backend/data/cl.saz`**（亦兼容 `backend/data/changlong.saz` 或项目根目录）。
- **秒级热重载**：代码具备文件修改监听机制，当在手机微信长龙小程序查票后导出新 `cl.saz` 覆盖时，**后台无需重启，秒级自动装载最新登录凭据**！
- **隐私安全保护**：包含个人会话凭证的 `cl.saz` 已被 [`.gitignore`] 严格忽略，绝不会被 Git 跟踪或误上传；已上传的 `changlong.db` 仅为长龙公开的航班与日历大盘数据，100% 不含任何个人身份信息。
- **获取步骤**：
  1. 下载并安装 Fiddler（[官方下载页](https://www.telerik.com/download/fiddler-everywhere)），开启 HTTPS 解密；
  2. 电脑打开微信「长龙航空」小程序，进入「畅飞卡」专区点开任意航线查一次票；
  3. Fiddler 点击 `File` ➔ `Save` ➔ `All Sessions...`，保存为 **`cl.saz`**；
  4. 存放到 `backend/data/cl.saz` 即可立刻享受实时穿透查票。
