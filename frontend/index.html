常见困惑解答：为什么在电脑网页上搜不到“长龙畅飞卡”？

阿里飞猪的“随心飞 / 飞行次卡 / 畅飞卡”属于特定航司权益卡产品。根据飞猪平台规则，卡券购买与兑换入口仅在移动端开放（飞猪 App 或 淘宝 App），PC 网页端主要提供常规现金机票搜索。因此请按照下方“3 步走”方式兑换！

1
第 1 步：在本助手做好航线规划与比价

利用本工具查清直飞航线、有效出行时段、避开屏蔽日，或计算就近高铁接驳规划。

2
第 2 步：打开手机【飞猪 App】或【淘宝 App】

进入右下角【我的】➔【我的卡券 / 机票卡券】，即可看到已购买的长龙畅飞卡（惠飞版/钻石版）。

3
第 3 步：点击【去预约 / 立即兑换】锁定机位

选择出发地与目的地，至少提前 3 天预约，支付当期对应阶梯票价与税费（机建+燃油），即可完成出票！
